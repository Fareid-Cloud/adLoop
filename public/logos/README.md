# الشعارات الرسمية

أسقِط ملفّ SVG هنا باسم مفتاح المنصّة **بحروف كبيرة**، ويظهر فوراً بلا أيّ
تعديل في الكود:

    SALLA.svg   ZID.svg   EASY_ORDERS.svg   SHOPIFY.svg   WOOCOMMERCE.svg
    BOSTA.svg   ARAMEX.svg   MYLERZ.svg   SMSA.svg
    WHATSAPP.svg   MESSENGER.svg   CLARITY.svg   GA4.svg
    GOOGLE_ADS.svg   META_ADS.svg   TIKTOK_ADS.svg   SNAPCHAT_ADS.svg

**من أين تؤخذ:** صفحة «العلامة التجارية / Brand assets / Press kit» لكلّ
شركة - هي المصدر الوحيد الذي يعطي الملفّ الرسميّ بأبعاده وألوانه الصحيحة،
وبشروط استخدامٍ مكتوبة.

**الشكل المطلوب:** SVG مربّع (`viewBox` متساوي الضلعين مثل `0 0 48 48`)،
والشعار داخله بهامشٍ بسيط. الشعارات المستطيلة الطويلة (الاسم كاملاً) تظهر
صغيرةً جداً داخل مربّعات ١٨-٢٨ بكسل - استعمل **الأيقونة** لا الاسم الكامل.

**بلا ملفّ:** يرسم المنتج علامةً مضمّنة إن كان يعرف هندستها يقيناً، وإلّا
شارة حرفٍ بلون العلامة. لا يُخترع شعارٌ ليس شعار الشركة.

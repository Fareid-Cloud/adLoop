# مجلّد فيديوهات الشرح

ضع ملفات الفيديو هنا. تُقدَّم مباشرةً على `/tutorials/<filename>` بلا أي إعداد.

## الأسماء المتوقَّعة

| الملف | يُعرَض في |
|---|---|
| `install-tracking-tag.mp4` | صفحة تغطية التتبّع + بطاقة "تحتاج مساعدة؟" في الرئيسية |
| `connect-platforms.mp4` | خطوة ربط المنصات |
| `select-campaigns.mp4` | خطوة اختيار الحملات |
| `read-truth-center.mp4` | مركز الحقيقة |

## الصيغة

- **MP4 (H.264)** — الأوسع توافقاً عبر المتصفّحات
- عرض ١٢٨٠ بكسل يكفي؛ أكبر من ذلك يضاعف الحجم بلا فرق مرئي
- **أقلّ من ١٠ ميجابايت للملف** — الفيديوهات تُقدَّم من نفس نطاق التطبيق،
  فالملف الثقيل يبطّئ الصفحة كلّها لا الفيديو وحده
